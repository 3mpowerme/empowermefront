# Resumen del producto

Aplicación web principal de EmpowerMe orientada a la experiencia del cliente para explorar servicios, gestionar su cuenta y ejecutar flujos guiados de negocio (por ejemplo, conceptualización y procesos administrativos).

## Funcionalidades principales
- Autenticación y gestión de sesión de usuarios.
- Dashboard con módulos por servicio y estado de avance.
- Flujos guiados (wizard) para completar procesos paso a paso.
- Visualización de planes, suscripciones y estados de pago.
- Interfaz responsive con enfoque mobile friendly.

## Arquitectura
- Frontend: React SPA.
- Estilos: Tailwind CSS + estilos del proyecto.
- Comunicación: consumo de API del backend mediante servicios y hooks.
- Internacionalización: soporte de recursos/locales definidos en `src/locales`.

## Experiencia de usuario
Interfaz orientada a claridad y conversión: navegación directa, componentes reutilizables, feedback visual en acciones críticas y adaptación consistente a móvil/escritorio.
